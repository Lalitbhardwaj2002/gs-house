# Permutations, combinations and counting principles

> Counting questions in the examination are short and reward a small stock of formulas: selections with and without repetition, the pigeon-hole principle, inclusion and exclusion, derangements, and the numbers of relations and functions between finite sets.

## Selections and arrangements

| Task | Number of ways |
| Arrange $n$ distinct objects in a row | $n!$ |
| Arrange $r$ out of $n$ distinct objects | $\frac{n!}{(n-r)!}$ |
| Choose $r$ out of $n$ distinct objects | $\binom{n}{r} = \frac{n!}{r!\,(n-r)!}$ |
| Arrange $n$ objects with $n_1, n_2, \dots$ alike | $\frac{n!}{n_1!\,n_2! \cdots}$ |
| Arrange $n$ distinct objects in a circle | $(n-1)!$ |
| Choose $r$ from $n$ kinds, repetition allowed | $\binom{n + r - 1}{r}$ |
| Non-negative integer solutions of $x_1 + \dots + x_n = r$ | $\binom{n + r - 1}{n - 1}$ |
| Positive integer solutions of $x_1 + \dots + x_n = r$ | $\binom{r - 1}{n - 1}$ |

- $\binom{n}{r} = \binom{n}{n-r}$, $\binom{n}{r} = \binom{n-1}{r} + \binom{n-1}{r-1}$, $\sum_r \binom{n}{r} = 2^n$, and $\sum_r \binom{n}{r}^2 = \binom{2n}{n}$.
- The number of subsets of an $n$-set is $2^n$; of subsets with an even number of elements, $2^{n-1}$ for $n \ge 1$.

## Pigeon-hole principle

- If $n + 1$ objects are placed in $n$ boxes, some box holds at least two.
- **Generalised form**: if $N$ objects are placed in $k$ boxes, some box holds at least $\lceil N/k \rceil$.
- Typical uses: among any $n + 1$ integers two have the same remainder modulo $n$; among any $n + 1$ numbers from $\{1, \dots, 2n\}$ one divides another, and two are coprime; in any group of 6 people there are 3 mutual friends or 3 mutual strangers.

## Inclusion and exclusion

- $\lvert A \cup B \rvert = \lvert A \rvert + \lvert B \rvert - \lvert A \cap B \rvert$.
- $\lvert A \cup B \cup C \rvert = \sum \lvert A \rvert - \sum \lvert A \cap B \rvert + \lvert A \cap B \cap C \rvert$, and so on with alternating signs.
- Numbers up to $N$ divisible by none of the primes $p_1, \dots, p_k$: $N - \sum \lfloor N/p_i \rfloor + \sum \lfloor N/(p_i p_j) \rfloor - \dots$.
- **Euler's function**: $\varphi(n) = n \prod_{p \mid n} \left(1 - \frac{1}{p}\right)$ comes from the same principle.

! remember | Derangements and onto functions
- A **derangement** is a permutation with no fixed point. $D_n = n! \left( 1 - \frac{1}{1!} + \frac{1}{2!} - \dots + \frac{(-1)^n}{n!} \right)$, the integer nearest to $\frac{n!}{e}$ for $n \ge 1$.
- $D_1, \dots, D_6 = 0, 1, 2, 9, 44, 265$, and $D_n = (n-1)(D_{n-1} + D_{n-2})$ for $n \ge 3$.
- Permutations of $n$ objects with exactly $k$ fixed points: $\binom{n}{k} D_{n-k}$.
- **Onto functions** from an $m$-set to an $n$-set: $\sum_{k=0}^{n} (-1)^k \binom{n}{k} (n - k)^m$. For $n = 2$ this is $2^m - 2$.

## Functions and relations on finite sets

Let $\lvert A \rvert = m$ and $\lvert B \rvert = n$.

| Object | Number |
| Functions $A \to B$ | $n^m$ |
| One-one functions $A \to B$ ($m \le n$) | $n(n-1) \cdots (n - m + 1)$ |
| Bijections of an $n$-set | $n!$ |
| Relations from $A$ to $B$ | $2^{mn}$ |
| Relations on an $n$-set | $2^{n^2}$ |
| Reflexive relations on an $n$-set | $2^{n^2 - n}$ |
| Symmetric relations on an $n$-set | $2^{n(n+1)/2}$ |
| Reflexive and symmetric relations | $2^{n(n-1)/2}$ |
| Antisymmetric relations | $2^n \cdot 3^{n(n-1)/2}$ |
| Irreflexive relations; asymmetric relations | $2^{n^2 - n}$; $3^{n(n-1)/2}$ |
| Equivalence relations (partitions) on an $n$-set | Bell number $B_n$: 1, 2, 5, 15, 52 for $n = 1, \dots, 5$ |
| Binary operations on an $n$-set | $n^{n^2}$; commutative ones: $n^{n(n+1)/2}$ |

- The number of partitions of an $n$-set into exactly $k$ blocks is the Stirling number $S(n,k)$; the number of onto functions is $n!\,S(m,n)$.
- The number of partitions of the integer $n$ is $p(n)$: 1, 2, 3, 5, 7, 11, 15 for $n = 1, \dots, 7$.

? How many derangements of 4 objects? :: 9.
? Non-negative integer solutions of $x + y + z = 10$? :: $\binom{12}{2} = 66$.
? How many relations on a set with $n$ elements are symmetric? :: $2^{n(n+1)/2}$.
? How many equivalence relations on a 4-element set? :: 15.

- Counting functions, relations and equivalence relations with a given property.
- Distribution problems solved by "stars and bars" or by inclusion and exclusion.
- Arguments by the pigeon-hole principle, and derangement counts.

! recap | One-minute revision
- Repetition allowed: $\binom{n + r - 1}{r}$. Circle: $(n-1)!$.
- $D_n \approx n!/e$: 0, 1, 2, 9, 44. Onto functions by inclusion and exclusion.
- Relations on an $n$-set: $2^{n^2}$; reflexive $2^{n^2 - n}$; symmetric $2^{n(n+1)/2}$; equivalence relations: Bell numbers.
