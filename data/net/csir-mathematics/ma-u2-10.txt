# Class equation and the Sylow theorems

> Conjugation splits a group into classes, and counting them gives the class equation. The Sylow theorems say which subgroups of prime-power order must exist and how many there can be; together they decide the structure of most groups of small order.

## Conjugacy classes and the class equation

- $a$ and $b$ are **conjugate** if $b = gag^{-1}$ for some $g$. The class of $a$ has $[G : C(a)]$ elements, so its size divides $\lvert G \rvert$.
- $a \in Z(G)$ if and only if its class is $\{a\}$.
- **Class equation**: $\lvert G \rvert = \lvert Z(G) \rvert + \sum [G : C(a_i)]$, the sum over one element from each class of size greater than 1.

| Group | Class equation |
| $S_3$ | $6 = 1 + 2 + 3$ |
| $D_4$, $Q_8$ | $8 = 1 + 1 + 2 + 2 + 2$ |
| $A_4$ | $12 = 1 + 3 + 4 + 4$ |
| $S_4$ | $24 = 1 + 3 + 6 + 6 + 8$ |
| $A_5$ | $60 = 1 + 12 + 12 + 15 + 20$ |

- The number of conjugacy classes of $D_n$ ($n \ge 3$) is $\frac{n + 3}{2}$ for odd $n$ and $\frac{n + 6}{2}$ for even $n$.
- A group is abelian if and only if every class has one element. The number of classes equals $\lvert G \rvert$ only then.
- The probability that two random elements commute is $\frac{k}{\lvert G \rvert}$, where $k$ is the number of classes; for a non-abelian group it is at most $\frac{5}{8}$.

! remember | Consequences for $p$-groups
- A group of order $p^n$ ($n \ge 1$) has a non-trivial centre.
- A group of order $p^2$ is abelian: it is $\mathbb{Z}_{p^2}$ or $\mathbb{Z}_p \times \mathbb{Z}_p$.
- A non-abelian group of order $p^3$ has centre of order $p$ and $G/Z(G) \cong \mathbb{Z}_p \times \mathbb{Z}_p$.
- A group of order $p^n$ has a normal subgroup of every order $p^k$, $0 \le k \le n$.
- **Cauchy's theorem**: if a prime $p$ divides $\lvert G \rvert$, then $G$ has an element of order $p$.

## Sylow theorems

Let $G$ be a finite group with $\lvert G \rvert = p^n m$, $p$ prime and $p \nmid m$. A subgroup of order $p^n$ is a **Sylow $p$-subgroup**; $n_p$ denotes their number.

- **First**: $G$ has a subgroup of order $p^k$ for every $k \le n$; in particular a Sylow $p$-subgroup exists.
- **Second**: any two Sylow $p$-subgroups are conjugate, and every $p$-subgroup lies in some Sylow $p$-subgroup.
- **Third**: $n_p \equiv 1 \pmod{p}$ and $n_p$ divides $m$. Also $n_p = [G : N(P)]$.
- A Sylow $p$-subgroup is normal if and only if $n_p = 1$.
- If all Sylow subgroups are normal, $G$ is their direct product (a **nilpotent** group).

! trick | Using the theorems
- List the numbers of the form $1 + kp$ that divide $m$; these are the possible values of $n_p$.
- Sylow $p$-subgroups of order $p$ meet only in $e$, so they contribute $n_p (p - 1)$ elements of order $p$. Count elements to rule out possibilities.
- Order 15: $n_3 \in \{1\}$, $n_5 \in \{1\}$, so the group is $\mathbb{Z}_3 \times \mathbb{Z}_5 \cong \mathbb{Z}_{15}$.
- Order 30: if $n_3 = 10$ and $n_5 = 6$ there would be $20 + 24 = 44$ elements, too many; so a Sylow 3- or 5-subgroup is normal and the group is not simple.

## Groups of small or special order

| Order | Groups up to isomorphism |
| $p$ (prime) | 1: $\mathbb{Z}_p$ |
| $p^2$ | 2, both abelian |
| $pq$, $p < q$, $p \nmid q - 1$ | 1: cyclic (for example 15, 33, 35) |
| $pq$, $p < q$, $p \mid q - 1$ | 2: cyclic and one non-abelian (for example 6, 10, 14, 21) |
| $2p$, $p$ odd | 2: $\mathbb{Z}_{2p}$ and $D_p$ |
| 4 | 2: $\mathbb{Z}_4$, $V_4$ |
| 6 | 2: $\mathbb{Z}_6$, $S_3$ |
| 8 | 5: $\mathbb{Z}_8$, $\mathbb{Z}_4 \times \mathbb{Z}_2$, $\mathbb{Z}_2^3$, $D_4$, $Q_8$ |
| 12 | 5: two abelian, $A_4$, $D_6$, and the dicyclic group |
| $p^3$ | 5: three abelian and two non-abelian |

- Groups of order $pq$, $p^2 q$ and $pqr$ ($p, q, r$ distinct primes) are never simple. The smallest non-abelian simple group is $A_5$, of order 60; the next has order 168.
- A group of order $n$ is necessarily cyclic exactly when $\gcd(n, \varphi(n)) = 1$.

## Group actions

- $G$ **acts** on a set $X$ if $e \cdot x = x$ and $g \cdot (h \cdot x) = (gh) \cdot x$. An action is the same as a homomorphism $G \to S_X$.
- **Orbit-stabiliser theorem**: $\lvert \operatorname{Orb}(x) \rvert = [G : \operatorname{Stab}(x)]$.
- **Burnside's lemma**: the number of orbits is $\frac{1}{\lvert G \rvert} \sum_{g \in G} \lvert \operatorname{Fix}(g) \rvert$.
- If a group of order $p^n$ acts on a finite set $X$, the number of fixed points is congruent to $\lvert X \rvert$ modulo $p$.
- If $H$ has index $n > 1$ in a finite group $G$, the action on cosets gives a homomorphism $G \to S_n$ with kernel inside $H$. So if $\lvert G \rvert$ does not divide $n!$, $G$ is not simple.

? Class equation of $S_3$? :: $6 = 1 + 2 + 3$.
? Why is every group of order $p^2$ abelian? :: Its centre is non-trivial, so $G/Z(G)$ is trivial or cyclic of order $p$, which forces $G$ abelian.
? Possible numbers of Sylow 2-subgroups in a group of order 12? :: 1 or 3.
? How many groups of order 8 are there? :: Five: three abelian, plus $D_4$ and $Q_8$.

! recap | One-minute revision
- Class sizes divide $\lvert G \rvert$; $p$-groups have non-trivial centre; order $p^2$ is abelian.
- $n_p \equiv 1 \pmod{p}$ and $n_p \mid m$; normal exactly when $n_p = 1$.
- Order $pq$ with $p \nmid q - 1$ is cyclic; smallest non-abelian simple group has order 60.
