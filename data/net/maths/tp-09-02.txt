# Trigonometric identities

> The compound-angle formulas give everything else: double and triple angles, sums turned into products and back, and the range of $a\sin x + b\cos x$. Conditional identities for the angles of a triangle are favourite MCQs.

## Compound, multiple and sub-multiple angles

! note | Compound, multiple and sub-multiple angles
- $\sin^2\theta + \cos^2\theta = 1$, $1 + \tan^2\theta = \sec^2\theta$, $1 + \cot^2\theta = \operatorname{cosec}^2\theta$.
- $\sin(A \pm B) = \sin A\cos B \pm \cos A\sin B$; $\cos(A \pm B) = \cos A\cos B \mp \sin A\sin B$;
$$\tan(A \pm B) = \frac{\tan A \pm \tan B}{1 \mp \tan A\tan B}.$$
- $\sin 2\theta = 2\sin\theta\cos\theta = \frac{2\tan\theta}{1 + \tan^2\theta}$;
$$\begin{aligned} &\cos 2\theta = \cos^2\theta - \sin^2\theta \\ &= 2\cos^2\theta - 1 = 1 - 2\sin^2\theta \\ &= \frac{1 - \tan^2\theta}{1 + \tan^2\theta}; \end{aligned}$$
$\tan 2\theta = \frac{2\tan\theta}{1 - \tan^2\theta}$.
- $\sin 3x = 3\sin x - 4\sin^3 x$; $\cos 3x = 4\cos^3 x - 3\cos x$; $\tan 3x = \frac{3\tan x - \tan^3 x}{1 - 3\tan^2 x}$.
- Sum to product: $\sin A + \sin B = 2\sin\frac{A+B}{2}\cos\frac{A-B}{2}$; $\sin A - \sin B = 2\cos\frac{A+B}{2}\sin\frac{A-B}{2}$; $\cos A + \cos B = 2\cos\frac{A+B}{2}\cos\frac{A-B}{2}$; $\cos A - \cos B = -2\sin\frac{A+B}{2}\sin\frac{A-B}{2}$.
- Product to sum: $2\sin A\cos B = \sin(A + B) + \sin(A - B)$; $2\cos A\cos B = \cos(A + B) + \cos(A - B)$; $2\sin A\sin B = \cos(A - B) - \cos(A + B)$.
- $\sin(A + B)\sin(A - B) = \sin^2 A - \sin^2 B$; $\cos(A + B)\cos(A - B) = \cos^2 A - \sin^2 B$.
- $a\sin x + b\cos x$ lies in $\left[-\sqrt{a^2 + b^2}, \sqrt{a^2 + b^2}\right]$; the equation $a\sin x + b\cos x = k$ is solvable iff $\lvert k \rvert \leq \sqrt{a^2 + b^2}$.

! check | Conditions added
The $\tan$ formulas need every tangent in them to be defined and the denominator non-zero: $\tan(A + B)$ needs $\tan A\tan B \neq 1$, $\tan(A - B)$ needs $\tan A\tan B \neq -1$, $\tan 2\theta$ needs $\tan^2\theta \neq 1$, $\tan 3x$ needs $\tan^2 x \neq \frac{1}{3}$. The range of $a\sin x + b\cos x$ assumes $a$, $b$ real and not both zero.

! example | Question TI1 — standard
Find $\sin 75°$ and $\tan 15°$.
**Solution.**
$$\begin{aligned} &\sin 75° = \sin(45° + 30°) \\ &= \frac{1}{\sqrt{2}} \cdot \frac{\sqrt{3}}{2} + \frac{1}{\sqrt{2}} \cdot \frac{1}{2} \\ &= \boxed{\frac{\sqrt{3} + 1}{2\sqrt{2}}}. \end{aligned}$$
$$\begin{aligned} &\tan 15° = \tan(45° - 30°) \\ &= \frac{1 - \frac{1}{\sqrt{3}}}{1 + \frac{1}{\sqrt{3}}} \\ &= \frac{\sqrt{3} - 1}{\sqrt{3} + 1} \\ &= \boxed{2 - \sqrt{3}}. \end{aligned}$$

! example | Question TI2 — standard
Prove that $\frac{\sin A + \sin 3A}{\cos A + \cos 3A} = \tan 2A$.
**Solution.** Numerator $= 2\sin 2A\cos A$, denominator $= 2\cos 2A\cos A$; ratio $= \tan 2A$.

! check | Condition added
The identity holds where its left side is defined: $\cos A + \cos 3A = 2\cos 2A\cos A \neq 0$, i.e. $\cos A \neq 0$ and $\cos 2A \neq 0$. Only then may the factor $2\cos A$ be cancelled.

! example | Question TI3 — standard
Find the maximum value of $3\sin x + 4\cos x$.
**Solution.** $\sqrt{3^2 + 4^2} = \boxed{5}$ (and minimum $-5$).

! trick | Shortcut / time-saver
If $A + B + C = \pi$: $\tan A + \tan B + \tan C = \tan A\tan B\tan C$; $\sin 2A + \sin 2B + \sin 2C = 4\sin A\sin B\sin C$; $\cot A\cot B + \cot B\cot C + \cot C\cot A = 1$. $\sin x\sin(60° - x)\sin(60° + x) = \frac{1}{4}\sin 3x$.
$$\begin{aligned} &\cos A\cos 2A\cos 4A \\ &\quad \cdots\cos 2^{n-1}A \\ &= \frac{\sin 2^nA}{2^n\sin A}. \end{aligned}$$

! check | Conditions added
The $\tan$ identity needs all three tangents defined: no angle an odd multiple of $\frac{\pi}{2}$ (in a triangle: no right angle). The $\cot$ identity needs no angle a multiple of $\pi$, which is automatic in a triangle. The product formula needs $\sin A \neq 0$.

## What it means

- **Where they come from**: everything follows from $\cos(A - B) = \cos A\cos B + \sin A\sin B$ (the distance between two points of the unit circle); put $B \to -B$, $A \to \frac{\pi}{2} - A$, then $B = A$ for the double angles.
- **Half angles** are the double-angle formulas read backwards: $\cos^2\frac{\theta}{2} = \frac{1 + \cos\theta}{2}$, $\sin^2\frac{\theta}{2} = \frac{1 - \cos\theta}{2}$, $\tan\frac{\theta}{2} = \frac{1 - \cos\theta}{\sin\theta}$.
- **$a\sin x + b\cos x$** $= \sqrt{a^2 + b^2}\,\sin(x + \alpha)$ with $\tan\alpha = \frac{b}{a}$ (for $a > 0$), which is why its values fill exactly $\left[-\sqrt{a^2 + b^2}, \sqrt{a^2 + b^2}\right]$.

! example | Example 1 — a product of cosines
Find $\cos 20°\cos 40°\cos 80°$.
**Solution.** With $A = 20°$, $n = 3$:
$$\frac{\sin 160°}{8\sin 20°} = \frac{\sin 20°}{8\sin 20°} = \boxed{\frac{1}{8}}.$$

! example | Example 2 — a half angle
Find $\cos 15°$ from $\cos 30°$.
**Solution.** $\cos^2 15° = \frac{1 + \cos 30°}{2} = \frac{2 + \sqrt{3}}{4}$, so $\cos 15° = \boxed{\frac{\sqrt{2 + \sqrt{3}}}{2}} = \frac{\sqrt{3} + 1}{2\sqrt{2}}$.

! example | Example 3 — a range
Find the greatest and least values of $5\cos x + 12\sin x + 7$.
**Solution.** $\sqrt{25 + 144} = 13$: greatest $13 + 7 = \boxed{20}$, least $-13 + 7 = \boxed{-6}$.

? $\cos 3x$ in terms of $\cos x$? :: $4\cos^3 x - 3\cos x$.
? $\cos A - \cos B$ as a product? :: $-2\sin\frac{A+B}{2}\sin\frac{A-B}{2}$.
? Range of $a\sin x + b\cos x$? :: $\left[-\sqrt{a^2 + b^2}, \sqrt{a^2 + b^2}\right]$.
? If $A + B + C = \pi$, $\tan A + \tan B + \tan C = $? :: $\tan A\tan B\tan C$.

! exam | What the exam asks
- Values like $\sin 75°$, $\tan 15°$, $\cos 20°\cos 40°\cos 80°$.
- Proving identities with sum–product and multiple-angle formulas.
- Maximum and minimum of $a\sin x + b\cos x + c$; identities when $A + B + C = \pi$.

! recap | One-minute revision
- $\sin 2\theta = \frac{2\tan\theta}{1 + \tan^2\theta}$, $\cos 2\theta = \frac{1 - \tan^2\theta}{1 + \tan^2\theta}$.
- $\sin 3x = 3\sin x - 4\sin^3 x$, $\cos 3x = 4\cos^3 x - 3\cos x$.
- $a\sin x + b\cos x \in \left[-\sqrt{a^2 + b^2}, \sqrt{a^2 + b^2}\right]$.
